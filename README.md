# IMG Squeeze CLI (imsq)

カレントディレクトリ内の画像を最適化（圧縮・リサイズ・フォーマット変換）し、指定フォルダへ一括出力するCLIツールです。
このツールはAIを使用して作成しました。各環境での動作保証はありません。

## 特徴

- **簡単な一括最適化** — カレントディレクトリ内の画像をスキャンし、まとめて処理します
- **多様なフォーマット対応** — `jpg`, `png`, `gif`, `webp` への変換をサポート
- **ファイルサイズ制限** — 目標サイズを指定すると品質を自動調整して収まるように圧縮
- **柔軟なリサイズ** — ピクセル指定・パーセント指定・ストレッチに対応
- **メタデータ保持** — Exif・ICCプロファイルなどを残すオプション
- **連番リネーム** — 桁数を `*` の数で指定できるパターン形式
- **対話モード** — 処理対象の画像をインタラクティブに選択
- **出力先指定** — 任意のディレクトリへ出力可能
- **再帰処理** — サブディレクトリ内の画像もディレクトリ構造を維持して処理
- **監視モード** — ディレクトリ内を監視して、新しい画像が増えたら自動で処理します
- **プリセット機能** — よく使う設定を名前付きで保存し、ワンコマンドで呼び出せます
- **安全設計** — 既定では `optimized/` などの出力先フォルダへ保存

---

## このツールについて詳しく

IMG Squeeze CLI は、Node.js の画像処理ライブラリ **[sharp](https://sharp.pixelplumbing.com/)** のラッパーです。
画像の圧縮・リサイズ・フォーマット変換はすべて sharp が行っており、このツールはその機能をコマンドラインから手軽に使えるようにしたものです。

### 類似ツールとの違い

> **注**: 以下の比較は AI による調査に基づくものです。調査時点での情報であり、各ツールの最新状況と異なる場合があります。

sharp をベースにした CLI ツールはすでに多数存在します（`sharp-cli`、`imagemin-cli` など）。  
`imsq` がそれらと異なる点は、**ターミナル作業中の日常的な一括処理**に特化したユーザー体験にあります。

画像最適化 CLI の中で `imsq` が比較的特徴的だと考えられる点：

- **チェックボックス UI による対話的なファイル選択 (`-p`)** — 処理対象をインタラクティブに選べる画像最適化 CLI は少なく、他ツールでは glob パターンや別の TUI ツールとの組み合わせが必要になることが多いです
- **複数フォーマット横断の目標サイズ自動調整 (`-s`)** — `jpegoptim` など JPEG 専用で目標サイズ指定ができるツールはありますが、jpg/png/gif/webp を横断して対応する汎用 CLI ツールは見当たりませんでした

他ツールでも実現可能だが `imsq` がまとめて提供している点：

- **設定の自動記憶** — 前回のオプションを `~/.imsq/options.json` に保存し、引数なし実行で再利用できます（`optimizt` はプロジェクト単位の設定ファイルで似た機能を持ちます）
- **実行前確認モード (`-c`)** — 処理開始前にオプションを確認・上書きできます
- **再帰処理のディレクトリ構造維持 (`-r`)** — `imagemin-cli` の標準機能にはありませんが、他ツールでは対応しているものもあります
- **安全な上書き設計** — 出力先が元ファイルと同一の場合、一時ファイルを経由して差し替えます

「コマンドを覚えずに画像をまとめて最適化したい」「毎回同じオプションで処理したい」といった用途で、これらの機能をひとつのツールにまとめて提供することを目指して作られています。

## インストール

```bash
git clone https://github.com/naorbieta/imgsqueeze-cli.git
cd imgsqueeze-cli
npm install
npm run build
npm link
```

`npm link` で任意のディレクトリから `imsq` コマンドが使えるようになります。

## 使い方

```bash
imsq [オプション]
```

### 直前の設定を引き継ぐ

引数なしで `imsq` を実行すると、前回使ったオプションを再利用します。
ただし `-p` と `-c` は引き継がれず、使うたびに毎回明示指定が必要です。

### オプションの初期化

`init` は、前回設定を引き継いだ状態をその場で解除したいときに使います。
通常の CLI 引数を1つでも指定した実行では前回設定は引き継がれないため、`imsq -d init` のような書き方ではほとんど意味がありません。

```bash
imsq -c
# 確認プロンプト内で
init
# または個別に解除
-d init -l init
```

### リネームのみ

`-n` だけを指定した場合は、圧縮せずに元ファイルをコピーしてリネームします。

### オプション一覧

| オプション | 短縮形 | 説明 |
| :--- | :--- | :--- |
| `--format <type>` | `-f` | 出力フォーマット変換 (`jpg`, `png`, `gif`, `webp`) |
| `--size <size>` | `-s` | 目標ファイルサイズ上限 (例: `100kb`, `1mb`) |
| `--length <dims>` | `-l` | リサイズ指定（後述） |
| `--recursive` | `-r` | サブディレクトリ内の画像も処理する |
| `--keep` | `-k` | メタデータを保持する (Exif, ICC profileなど) |
| `--name <pattern>` | `-n` | リネームパターン (`?` = 元ファイル名, `*` の数で連番桁数を指定) |
| `--pick` | `-p` | 対話モード: 処理対象の画像を選択する |
| `--directory <dir>` | `-d` | 出力先ディレクトリ指定 |
| `--confirm` | `-c` | 処理を開始する前に確認を挟む (`-p` と併用時は選択後) |
| `--hard` |  | 出力成功後に元ファイルをゴミ箱へ送らず削除する |
| `--trash` |  | 出力成功後に元ファイルをゴミ箱へ送る |
| `--watch` | `-w` | 監視モード: ディレクトリを監視し、新規追加画像を自動処理 |
| `--no-initial` |  | 監視モード時、起動時に存在する既存ファイルの処理をスキップする |
| `preset [name]` |  | プリセットを読み込んで処理（引数なしで一覧表示） |
| `preset save <name>` |  | 現在の保存済みオプションをプリセットとして保存 |
| `preset delete <name>` |  | プリセットを削除 |
| `--version` | `-v` | バージョン表示 |
| `--help` | `-h` | ヘルプ表示 |

## 使用例

### フォーマット変換

```bash
# すべての画像を WebP に変換
imsq -f webp
```

### ファイルサイズ制限

```bash
# 100KB 以下になるよう品質を自動調整して圧縮
imsq -s 100kb
```

品質を段階的に下げて目標サイズに収まるよう試行します。最低品質でも超過する場合は警告が表示されます。

### リサイズ

```bash
# 横幅を最大 600px にリサイズ（アスペクト比維持）
imsq -l w:600

# 高さを最大 400px にリサイズ（アスペクト比維持）
imsq -l h:400

# 横幅 50% に縮小（元画像に対するパーセント指定）
imsq -l w:50%

# 横幅と高さを両方パーセント指定（アスペクト比維持）
imsq -l w:50%,h:50%

# 横幅・高さを両方ピクセル指定 → ストレッチ（アスペクト比無視）
imsq -l w:200,h:100
```

> **ストレッチについて**
> `w` と `h` の両方をピクセル数で指定した場合のみ、アスペクト比を無視してその寸法ぴったりに変形します。
> パーセント指定や片方のみ指定の場合はアスペクト比を維持します。

### メタデータ保持

```bash
# Exif や ICC プロファイルを保持したまま圧縮
imsq -k
```

### 連番リネーム

`?` で元ファイル名、`*` の数で連番の桁数を指定します。

```bash
# example.jpg -> example_optimize.jpg
imsq -n "?_optimize"

# img_001.jpg, img_002.jpg, ... と出力
imsq -n "img_***"

# example.jpg -> example_01.jpg, sample.jpg -> sample_02.jpg
imsq -n "?_**"

# photo_01.png, photo_02.png, ... と出力
imsq -n "photo_**" -f png

# 1.jpg, 2.jpg, 10.jpg, ... と出力（桁あわせなし）
imsq -n "*"
```

### 対話モード

```bash
imsq -p
```

起動するとスキャン後に一覧が表示され、スペースキーで処理したい画像を選択、Enterで確定できます。  
EscキーまたはCtrl+Cでキャンセルします。

### 確認モード

```bash
imsq -c
```

処理を開始する前に確認を挟みます。`-p` と併用した場合は、先に画像を選択してから確認画面に進み、選択されたファイル名も表示されます。`y` / `n` に加えて、ここで追加のオプションを入力してその場で上書きできます。他のオプションと組み合わせて使えます。
`init` を単体で入力すると、その実行中の設定をいったん初期化し、`-d init` のように個別初期化もできます。

```bash
# 対話で選択してから確認を経て処理開始
imsq -p -c -f webp
```

### 出力先ディレクトリ指定

```bash
# カレントディレクトリ内の ./output フォルダへ出力
imsq -d ./output

# カレントディレクトリそのものへ出力（上書きに注意）
imsq -d .

# 絶対パス指定
imsq -d /Users/me/Pictures/compressed
```

未指定の場合、カレントディレクトリ内に `optimized/`（重複時は `optimized_1/` など）が自動生成されます。

`-d .` などで出力先が元ファイルと同一パスになる場合、既定では元ファイルをゴミ箱へ送ってから差し替えます。

### 元ファイルの処理

```bash
# 出力成功後、元ファイルをゴミ箱へ送る
imsq -d . -f webp --trash

# 出力成功後、元ファイルをゴミ箱へ送らず削除する
imsq -d . -f webp --hard
```

- `--trash` は、出力先が別ファイルでも出力成功後に元ファイルをゴミ箱へ送ります
- `--hard` は、出力先が別ファイルでも出力成功後に元ファイルを削除します
- `--hard` と `--trash` は同時に指定できません

### 監視モード

```bash
# カレントディレクトリを監視し、新規画像が追加されたら自動的に最適化
imsq -w

# 起動時の既存画像をスキップし、起動後に追加された画像のみを自動最適化
imsq -w --no-initial

# WebPに変換かつ100kb以下になるよう調整する設定で監視を行う
imsq -w -f webp -s 100kb
```

- `-w` / `--watch` オプションで監視モードが起動します。
- デフォルトでは、起動時にカレントディレクトリに存在する画像ファイルをすべて一括処理したのち、監視状態（待機状態）に入ります。
- `--no-initial` を併用すると、起動時に存在する既存ファイルは処理せず、起動後に追加されたファイルだけを処理します。
- 出力先ディレクトリ（`-d` で指定したパス、または自動生成される `optimized/` などのディレクトリ）は、無限ループ防止のため自動的に監視対象から除外されます。
- 監視を終了するには、ターミナルで `Ctrl+C` を入力します。

### 組み合わせ例

```bash
# サブディレクトリも含めて再帰処理、WebP に変換、横幅 1280px にリサイズ、メタデータ保持
imsq -r -f webp -l w:1280 -k

# 対話で画像を選択し、100kb 以下に圧縮して ./dist へ出力
imsq -p -s 100kb -d ./dist

# 画像を選択して連番リネームし thumb_001.jpg 形式で出力
imsq -p -n "thumb_***" -f jpg
```

## プリセット機能

よく使う設定の組み合わせを名前付きで保存し、`imsq preset <name>` でいつでも呼び出せます。

### コマンド

```bash
# プリセット一覧を表示
imsq preset

# プリセットを読み込んで処理実行
imsq preset web
imsq preset 1          # 番号（1-indexed）でも指定可

# 現在の保存済みオプション（~/.imsq/options.json）をプリセットとして保存
imsq preset save web
imsq preset save width1200

# プリセットを削除
imsq preset delete web
imsq preset delete 1   # 番号でも削除可（del / rm でも可）
```

### プリセットとCLIオプションの組み合わせ

プリセット読み込み時に追加でCLIオプションを指定すると、CLI側が優先されます。

```bash
# web プリセットを読み込みつつ、今回は jpg で出力
imsq preset web -f jpg

# width1200 プリセットを読み込みつつ、再帰処理も追加
imsq preset width1200 -r
```

### 設定ファイル（手動編集）

プリセットは `~/.imsq/presets.toml` に保存されます。テキストエディタで直接書くこともできます。

```toml
[web]
format = "webp"
size = "200kb"
recursive = true

[width1200]
format = "webp"
length = "w:1200"
keep = true

[thumb]
format = "jpg"
length = "w:400,h:400"
name = "thumb_***"
directory = "./thumbs"
```

#### 設定できるキー

| キー | 型 | 対応するCLIオプション | 例 |
| :--- | :--- | :--- | :--- |
| `format` | 文字列 | `-f` | `"webp"`, `"jpg"`, `"png"`, `"gif"` |
| `size` | 文字列 | `-s` | `"100kb"`, `"1mb"` |
| `length` | 文字列 | `-l` | `"w:1200"`, `"h:800"`, `"w:1200,h:800"`, `"w:50%"` |
| `recursive` | 真偽値 | `-r` | `true` / `false` |
| `keep` | 真偽値 | `-k` | `true` / `false` |
| `name` | 文字列 | `-n` | `"?_opt"`, `"img_***"` |
| `directory` | 文字列 | `-d` | `"./output"`, `"."` |

> **注意**: `-p`（対話モード）、`-c`（確認モード）、`--hard`、`--trash`、`-w`（監視モード）はプリセットに保存・読み込みされません。毎回明示指定してください。
